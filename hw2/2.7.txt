Складність алгоритмів. Асимптотична оцінка складності алгоритмів.
Завдання для самостійної роботи

f(n) = 3n^2 - n + 4             g(n) = (n log n) + 5
f(n) + g(n) = O(n^2)

константи C > 0 та n0 ≥ 0, такі що для всіх n ≥ n0 виконується:
f(n) + g(n) ≤ C * n^2

f(n) + g(n) = (3n^2 - n + 4) + (n log n + 5) = 3n^2 + n log n - n + 9

оцінка:
n^2 зростає швидше, ніж n log n або n;
n log n зростає повільніше ніж, ніж n^2, зокрема, для будь-якого n ≥ 2:
log n ≤ n, тому:
n log n ≤ n^2

|n| ≤ n^2, для n ≥ 1

9 - це стала, яку можна обмежити множником n^2 для достатньо великих n

f(n) + g(n) = 3n^2 + n log n - n + 9 ≤ 3n^2 + n^2 + n^2 + n^2 = 6n^2

C = 6, n0 ≥ 2:
f(n) + g(n) ≤ C * n^2
f(n) + g(n) = O(n^2)
